Exchange Provisioner – Browser-Validierung

Shared Mailboxes & Distribution Groups: Daten prüfen, Vorschau ansehen, sauberes JSON für den Provisioning-Lauf erzeugen.

🔒 Keine Speicherung 🚫 Kein Netzwerkzugriff (per CSP erzwungen) 💻 Läuft zu 100 % lokal in diesem Tab 🗑️ Tab zu = Daten weg
Sicherheitsgarantien dieser Seite: Die eingebettete Content-Security-Policy (connect-src 'none') blockiert jeden Netzwerkaufruf – nachprüfbar über DevTools → Netzwerk-Tab, der leer bleibt. Es werden keine Cookies, kein localStorage, keine IndexedDB verwendet. Ihre Daten existieren nur im Arbeitsspeicher dieses Tabs und verschwinden vollständig, sobald Sie den Tab schließen oder „Alle Daten löschen" klicken.

1 · Einstellungen

Diese Werte müssen mit der config.json des Provisioning-Scripts übereinstimmen – das Script validiert serverseitig erneut (Defense in Depth).

2 · Shared Mailboxes

Erwartete Spalten: Vorname; Nachname; Zusatz; Anzeigename; PrimaereAdresse; Weiterleitung; FullAccess; SendAs; HiddenFromGAL (Pflicht: die ersten drei).

3 · Distribution Groups

Erwartete Spalten: Vorname; Nachname; Zusatz; Anzeigename; PrimaereAdresse; Mitglieder; Besitzer; HiddenFromGAL (Pflicht: die ersten drei).

4 · Ergebnis

    5 · Ausführung: Azure Cloud Shell (ephemeral) – Browser rein, Browser raus, nichts bleibt
    1. shell.azure.com im Browser öffnen → PowerShell wählen → beim Storage-Dialog „Kein Speicherkonto erforderlich" (ephemeral) auswählen. Einmal mit dem Admin-Konto einloggen (MFA wird unterstützt).
    2. Über das Upload-Symbol drei Dateien hochladen: Provisioning.ps1, config.json und die hier exportierte provisioning-data.json.
    3. Trockenlauf: ./Provisioning.ps1 -JsonInputFile provisioning-data.json -WhatIf
    4. Scharfer Lauf: ./Provisioning.ps1 -JsonInputFile provisioning-data.json – das ExchangeOnlineManagement-Modul ist in Cloud Shell vorinstalliert; ImportExcel wird im JSON-Modus nicht benötigt.
    5. Ergebnis-CSV bei Bedarf über das Download-Symbol sichern, dann Browser-Tab schließen → der ephemere Container wird vernichtet, nichts bleibt gespeichert.

    Warum nicht direkt aus dieser Seite heraus? Microsoft Graph kann keine Shared Mailboxes und keine klassischen Verteilergruppen anlegen, und die Exchange-Admin-API ist für Browser-Aufrufe gesperrt (kein CORS). Cloud Shell ist der von Microsoft unterstützte Weg, der trotzdem vollständig im Browser bleibt.
